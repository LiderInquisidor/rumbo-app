# Rumbo – Agencia de Viajes (MVP) · Frontend + Backend + MySQL (Railway)

## Correrlo en tu computador
```bash
pip install -r requirements.txt
python run.py               # abre http://localhost:5000
```
Al arrancar crea solas las tablas, las columnas nuevas, el administrador y 6 paquetes de ejemplo.
Si MySQL no conecta, el servidor muestra el error.

- Administrador: `admin@rumbo.com` / `Admin123*`
- Clientes: se registran desde la página.
